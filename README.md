# Quiz Website

A dynamic quiz website built with React and Vite, offering a selection of quizzes on various topics. Users can choose between an Operating Systems Quiz or a World Quiz, answer questions, and view their results upon completion.

## Features

- **Quiz Selection**: Choose between different quiz categories such as OS Quiz or World Quiz.
- **Interactive Questions**: Answer multiple-choice questions and get immediate feedback.
- **Result Display**: View the number of correct answers and detailed results at the end of the quiz.
- **Retry Option**: Easily reset the quiz to start over.

## Tech Stack

- **React**: A JavaScript library for building user interfaces.
- **Vite**: A build tool that provides a fast development environment.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **ESLint**: A tool for identifying and fixing problems in JavaScript code.

## Installation Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ArifRahaman/Quiz-website.git
   cd Quiz-website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview the production build**:
   ```bash
   npm run preview
   ```

## Usage Guide

- **Select a Quiz**: Use the dropdown menu to select either "OS Quiz" or "World Quiz".
- **Answer Questions**: Click on the options to answer each question.
- **View Results**: After completing the quiz, view your results and see which questions you answered correctly.
- **Retry**: Click "Retry" to start the quiz over.
